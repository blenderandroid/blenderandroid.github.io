## About this build

This APK is an experimental Blender 5.3 Alpha port for Android, shared for testing, study, and development feedback. It is not an official Blender Foundation release and does not have active support.

## Compatibility and technical details

- **Build profile:** Full
- **Architecture:** arm64-v8a (64-bit ARM devices only)
- **Minimum Android version:** Android 12 / API 31
- **Target SDK:** API 34
- **Graphics:** Vulkan
- **Application package:** `org.blender.blender`
- **Development and test device:** Samsung Galaxy S24 Ultra
- **Source commit:** [`1aeadf3`](https://github.com/Wanderson-Magalhaes/blender_for_android/commit/1aeadf3fea12dfaa75eac073175cd3b5c9a5333c)
- **Build date:** August 25, 2026

## Device support and limitations

This build has only been validated on a Samsung Galaxy S24 Ultra. It has not been verified on other phones, tablets, chipsets, Android versions, GPU drivers, or input configurations.

Unexpected crashes, rendering issues, missing features, poor performance, installation failures, and device-specific problems may occur. Touch, keyboard, mouse, stylus, window-management, and desktop-oriented Blender workflows should all be considered experimental on Android.
