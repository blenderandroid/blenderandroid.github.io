Wide support

simfeo / blender · alpha 3

The upstream port. Optimises for stability and for running on as many devices as possible, and ships in two sizes so weaker hardware is not left out.

  • ARM Mali devices now run. Three GPU features Blender required and mostly never used were dropped in alpha 3.
  • Full and Lite. Lite drops Cycles, video and the exchange formats for devices that cannot carry them.
  • A startup log you can send. Written to Download/blender-startup.log even when the app closes immediately.
  • Tested on Galaxy Tab S7 FE, Galaxy S22 Ultra and a Mali-G57 MC2.

Everything on

Wanderson-Magalhaes / blender_for_android · alpha 2

A fork of the upstream port that enables as much as it can and tunes the touch interface for one device. Developed and tested on a Galaxy S24 Ultra only.

  • Native audio. Timeline audio, sound strips and speaker objects play through the phone or headphones.
  • Tool variants on long press. Hold a tool to reach Select Box, Circle, Lasso and the rest of its group.
  • Phone-sized chrome. Menus, headers, toolbars and the properties column are enlarged for fingers.
  • Not validated on any other device, chipset, Android version or GPU driver.

Installing

  1. Allow the install

    These do not come from Google Play, so Android will ask you to permit installation from an unknown source. Grant it to your browser or file manager.

  2. Check the certificate

    The upstream APKs are signed by the author. Alpha 3 uses the same key as alpha 2, so it installs over it as an update and keeps your preferences.

  3. Wait out the first launch

    Around 100 MB of runtime data unpacks once per install, showing only the splash screen. It is not frozen.

Porting log

What changed, why it was broken, and what is still known to be wrong. Written as the work happens.

7 Sep 2026android-alpha-3Wide support

Devices with ARM Mali graphics now run

Blender required three GPU features that ARM's Mali driver does not provide, and never used two of them. Every device with Mali graphics was turned away before anything could appear on screen, and turned away in silence, because the reason was only written to a log a developer would need a cable to read.

Dual source blending and vertex stage stores are gone entirely. Clip distance is used only by the viewport clipping region, so dropping it costs that one feature rather than the renderer. Tested on a Mali-G57 MC2 with ARM's r32p1 driver. If an earlier build started and then closed itself, or never drew anything, this one is worth another try.

1 Sep 2026alpha.2-androidEverything on

Native audio, and a toolbar built for thumbs

Timeline audio, sound strips and speaker objects now play through the phone, wired headphones or whatever Android's current output is. Audio is in the Full build only. If the route changes while Blender is running, playback may stay stopped until the audio device is reopened; automatic recovery is not implemented yet.

Holding a tool opens its variants, editor borders are easier to grab with a finger, and closed side panels are easier to reopen and resize. Menus, headers, toolbars and the properties tab column are all larger for touch.

6 Sep 2026android-alpha-2Wide support

The port stopped building its own dependencies

It now takes the prebuilt Android library set published by the Blender project, the same way every other platform consumes its lib/<platform> set. That single change is what made the rest of this release possible.

Video is back through ffmpeg. Cycles denoising, fluid and smoke simulation, the Ocean modifier, path guiding, exact and manifold booleans, motion tracking, Draco glTF and PDF export all arrived with it. So did the missing content: the essentials asset library, which is where every brush comes from, 49 interface languages, and online extensions with pip.

25 Aug 2026alpha-androidEverything on

The fork opens, on one device

An experimental Blender 5.3 Alpha port shared for testing, study and development feedback, continuing the original Android work. Full profile, arm64-v8a, target SDK 34, package org.blender.blender.

Validated on a Samsung Galaxy S24 Ultra and nothing else. Touch, keyboard, mouse, stylus and window management should all be treated as experimental.
