7 Sep 2026android-alpha-3Wide support

Devices with ARM Mali graphics now run

Blender required three GPU features ARM's Mali driver does not provide, and never used two of them. Every Mali device was turned away in silence before anything reached the screen. If an earlier build refused to start, try this one.

6 Sep 2026android-alpha-2Wide support

The port stopped building its own dependencies

It now takes the prebuilt Android library set published by the Blender project. That single change is what brought back video, Cycles denoising, simulation, the exchange formats, 49 languages and every missing brush.

Native audio, and a toolbar built for thumbs

Timeline audio, sound strips and speaker objects now play through the phone or headphones, in the Full build only. Holding a tool opens its variants, and the whole interface grew for fingers.
